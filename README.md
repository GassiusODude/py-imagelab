# py-imagelab

Collection of image processing techniques.

Looking into some available resources in OpenCV and creating some scripts to test them out.

## Supported Recognition

| Support | Status |
| :-: | :-: |
| Face Detection | Good |
| Foreground/Background Separation | Slow |

This is described in more detail in [image_recognition.md](./docs/image_recognition.md)

## Processing

| Support | Status |
| :-: | :-: |
| Cartoonify | Can use adaptive adjustment of detail/blurring filters |

### Cartoonify

A simplification function to remove detail for an image and add emphasis on edges to make an image look more cartoonish.
